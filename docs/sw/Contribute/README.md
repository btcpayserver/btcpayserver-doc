# Jinsi ya kuchangia BTCPay Server?

BTCPay Server imejengwa na kudumishwa kikamilifu na wachangiaji wa kujitolea kwenye mtandao.

Tunakaribisha, tunashukuru, na tunahimiza michango mipya.

:::tip
Angalia [tovuti yetu ya wachangiaji wapya](https://contribute.btcpayserver.org) ili kuanza kuchangia mara moja.
:::

Kulingana na ujuzi wako na maslahi yako, unaweza kusaidia kwa njia kadhaa:

- [Programu](./Dev.md)
  - [Utengenezaji Programu](./DevCode.md)
  - [Upimaji Programu](./DevTest.md)
- [Uandishi](./Write.md)
  - [Zana](./WriteSoftware.md)
  - [Nyaraka](./WriteDocs.md)
  - [Blogu](./WriteBlog.md)
- [Ubunifu](./Design.md)
- [Ufasiri](./Translate.md)
- [Mengineyo](./Misc.md)

Kila mchango ni muhimu na ikiwa una maswali yoyote, jisikie huru kushauriana na [jamii yetu inayokua](../Community.md).
