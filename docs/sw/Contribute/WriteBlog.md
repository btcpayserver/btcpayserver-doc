# Changia kwenye blogu

Kwa sasa, blogu inahifadhiwa kwenye Wordpress na mchakato wa kuchangia hauhitaji Github.

Tuwasiliane nasi kwenye [mazungumzo](https://chat.btcpayserver.org) na tutajadili maandishi yaliyopendekezwa.

Mada zinazofaa kwa blogu ni pamoja na:

- Sasisho za BTCPay Server
- Mafunzo
- Ushuhuda wa jinsi BTCPay Server ilivyokusaidia

Kuandika makala kwenye [Blogu](https://blog.btcpayserver.org) yetu husaidia kueneza habari kuhusu vipengele vipya vinavyotekelezwa, au hutoa mafunzo kuhusu jinsi ya kuvitumia.
