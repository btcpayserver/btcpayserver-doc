# Usambazaji wa mtandao wa Comet Cash BTCPay Server

Mwongozo huu unaeleza jinsi ya kusambaza mfano unaosimamiwa wa BTCPay Server kupitia [Comet Cash](https://dashboard.cometcash.com/).

Comet Cash inatumia mikopo kutenga huduma zinazosimamiwa. Mpango wa Msingi (Basic) unagharimu **$30 kwa mwezi** na unajumuisha **mikopo 1,000**. Kila mfano wa BTCPay Server unahitaji **mikopo 250**, hivyo mpango wa Msingi unaweza kuendesha hadi mifano minne ya BTCPay Server. Ikiwa pia unahitaji Lightning, nodi ya LND inahitaji **mikopo 350**. Kwa mfano, mpango wa Msingi unaweza kuendesha mifano miwili ya BTCPay Server na nodi moja ya LND.

## 1. Ingia kwenye Comet Cash

Nenda kwenye [dashibodi ya Comet Cash](https://dashboard.cometcash.com/), ingiza anwani yako ya barua pepe, na ubofye `Pata Nambari ya Uthibitishaji` (Get Verification Code). Tumia nambari ya uthibitishaji iliyotumwa kwenye anwani yako ya barua pepe kumalizia kuingia.

![Comet Cash login](../../img/CometCash/1-login.png)

## 2. Washa mpango wako

Fungua ukurasa wa `Malipo` (Billing) kutoka kwenye utepe wa pembeni na washa mpango wa Msingi (Basic) au mpango mwingine unaotoa mikopo ya kutosha kwa huduma unazotaka kusambaza.

## 3. Unda nodi ya BTCPay Server

Fungua `Nodi Zangu` (My Nodes) kutoka kwenye utepe wa pembeni, kisha bofya `Nodi Mpya` (New Node).

![Comet Cash My Nodes page](../../img/CometCash/2-my-nodes.png)

Chagua `BTCPay Server`, ingiza jina la nodi, na uchague mtandao na eneo kwa mfano wako. Muhtasari wa agizo unaonyesha kuwa mfano wa BTCPay Server unahitaji `Mikopo 250`. Bofya `Unda Nodi` (Create Node) ili kuanza usambazaji.

![Create a Comet Cash BTCPay Server node](../../img/CometCash/3-create-node.png)

## 4. Fungua mfano wako wa BTCPay Server

Subiri hadi hali ya nodi ibadilike kuwa `inaendesha` (running). Fungua ukurasa wa maelezo ya nodi na ubofye `Fungua BTCPay Server` (Open BTCPay Server).

![Comet Cash BTCPay Server details](../../img/CometCash/4-btcpay-details.png)

## 5. Unda akaunti yako ya BTCPay Server

Mfano wako mpya unafungua ukurasa wa usajili wa BTCPay Server. Ingiza anwani yako ya barua pepe na nenosiri, kisha bofya `Unda akaunti` (Create account). Akaunti ya kwanza iliyosajiliwa kwenye mfano ni akaunti ya msimamizi.

![BTCPay Server account registration](../../img/CometCash/5-btcpay-register.png)

Sasa uko tayari kuunda duka lako la kwanza. Endelea na [mwongozo wa usajili wa BTCPay Server](../RegisterAccount.md), kisha fuata [mwongozo wa kusanidi pochi](../WalletSetup.md).

:::tip
Kwa maswali kuhusu dashibodi ya Comet Cash, malipo, au usambazaji wako unaosimamiwa, wasiliana na usaidizi wa Comet Cash.
:::
