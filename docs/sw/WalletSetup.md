# (3) Usanidi wa Pochi

Baada ya [usajili wa akaunti](/sw/RegisterAccount/) na [kuunda duka](/sw/CreateStore/), ni wakati wa kusanidi pochi ndani ya BTCPay Server yako, ili uanze kupokea malipo ndani yake.

Kuna njia kadhaa za kusanidi pochi katika BTCPay Server:

- [Unganisha pochi iliyokuwepo](/sw/ConnectWallet/)
- [Unda pochi mpya](/sw/CreateWallet/)
- [Sanidi pochi ya Lightning](/sw/LightningNetwork-Setup/)

Kuna chaguo nyingi za jinsi ya kusanidi pochi na BTCPay Server yako. Ni juu yako kuamua kile kinachofanya kazi vyema kwa matumizi yako. Ukishasanidi pochi, uko tayari. Hatua inayofuata, ni [kuanza kuchunguza vipengele](/sw/WhatsNext/).

**_Endelea kwenye hatua inayofuata - [Nini Kifuatavyo?](/sw/WhatsNext/)._**
